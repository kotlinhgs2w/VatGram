# ValGram

**ValGram** — Android-клиент Telegram, развиваемый на базе проекта YouGram.

> Текущий этап: подготовка переноса исходного проекта YouGram `v1.4.4-r`.
> Исходный код приложения пока не импортирован в этот репозиторий; этот README не означает, что сборка уже готова.

## Источник

- Upstream: https://github.com/julfy-0/Yougram
- Базовый релиз: https://github.com/julfy-0/Yougram/releases/tag/v1.4.4-r
- Зафиксированный upstream commit релиза: `426c0608ddd2ec156f92403ca4686357c8860733`

## План переноса

1. Импортировать полный исходный Git tree релиза `v1.4.4-r`, сохранив структуру модулей и историю происхождения.
2. Переименовать приложение и его брендинг в ValGram.
3. Проверить applicationId, версии SDK, Gradle/AGP, NDK и CMake.
4. Удалить любые upstream signing secrets/keystore из публикуемой сборки и настроить отдельную подпись ValGram.
5. Настроить CI для проверки Gradle-сборки.
6. Проверить сторонние зависимости и их лицензии отдельно от разрешения на сам YouGram.

## Требования upstream

Ориентир по сборке — JDK 17, Android SDK, Android NDK и CMake. Точные версии нужно сверить с Gradle-конфигурацией выбранного тега.

## Безопасность и секреты

- Не добавляйте `local.properties`, Telegram API hash, пароли, keystore или приватные ключи в Git.
- Для ValGram должна использоваться собственная signing key.
- Не используйте файл `yougram.jks` из upstream-репозитория для подписи ValGram.
- Перед публикацией проверьте лицензии TDLib, VoIP, плагинов и всех остальных сторонних компонентов.
