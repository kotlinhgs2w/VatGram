# Статус переноса YouGram → ValGram

Дата: 2026-11-21

## Исходные точки

- Upstream: https://github.com/julfy-0/Yougram
- Релиз: `v1.4.4-r`
- Commit релиза: `426c0608ddd2ec156f92403ca4686357c8860733`
- Целевой репозиторий: https://github.com/kotlinhgs2w/VatGram
- Целевая ветка: `main`

## Проверено

- Целевой репозиторий публичный, ветка `main`; до начала работ в нём находился только минимальный README.
- В теге upstream присутствуют модули `app`, `buildSrc`, `plugin-host`, `voip`, `navbar`, `ota`, `tools`, `docs` и Gradle-конфигурация.
- В upstream присутствует `yougram.jks`. Этот файл нельзя переносить или использовать для подписи ValGram.
- Конфигурация upstream включает Telegram API параметры и OTA/AI параметры; локальные секреты не должны попадать в Git.

## Ограничение текущего этапа

Доступные GitHub-действия в этой сессии позволяют читать файлы и создавать/обновлять отдельные Git-объекты, но не предоставляют операцию fork/import всего репозитория. Поэтому полный перенос десятков тысяч файлов и бинарных ресурсов одним безопасным действием сейчас не выполнен.

**Важно:** исходники YouGram пока не находятся в VatGram. Не запускайте Gradle build из этого репозитория, пока не будет выполнен полный импорт.

## Следующие действия

1. Выполнить полный Git-импорт upstream-тега в целевой репозиторий с сохранением commit history.
2. Исключить upstream keystore и любые секреты; добавить шаблон локальной конфигурации без реальных ключей.
3. Переименовать application label, package/applicationId, внутренние идентификаторы бренда и ресурсы в ValGram.
4. Проверить лицензии всех сторонних модулей и зависимостей.
5. Запустить сборку и исправить ошибки, которые подтвердятся логами CI.

## Подтверждение прав

Владелец проекта сообщил в переписке, что разрешает использовать свой проект. Объём этого разрешения следует документально зафиксировать отдельно, включая код, графику, брендинг и право публикации производной версии.
