- Commit релиза: `426c0608ddd2ec156f92403ca4686357c8860733`

## Проверка полученного архива

- Архив содержит 289 файлов (около 1,6 МБ распакованных данных).
- Это компактный Android-проект с модулем `:app`, Kotlin/Jetpack Compose и C++/JNI.
- В `app/build.gradle.kts`: `applicationId = "app.yougram"`, `versionName = "0.9.2"`, `minSdk = 31`, `compileSdk = 36`, Java/Kotlin target 17.
- Для нативной части требуется CMake 3.22.1 и Android NDK.
- В архиве нет исполняемого Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle-wrapper.jar`).
- Конфигурация по умолчанию задаёт Telegram API ID как `0`, а API Hash как пустую строку; для полноценной авторизации нужны собственные корректные значения.
- README архива указывает версию 0.8.4 / versionCode 18, но Gradle-конфигурация указывает 0.9.2 / versionCode 23. Эти метаданные расходятся и требуют сверки перед релизом.

## Безопасность

- В архиве есть `yougram.jks`. Он исключён из переноса и не должен использоваться для подписи ValGram.
- Не переносить `local.properties`, реальные API-ключи, пароли, keystore и другие секреты.
- Для ValGram создать отдельный signing key и хранить его вне Git.

## Что ещё не выполнено

- Исходники из загруженного ZIP ещё не импортированы в VatGram.
- APK не собран и не проверен на устройстве.
- Package/applicationId и брендинг пока не переименованы в ValGram.

## Блокеры сборки в текущей среде

- В доступной среде отсутствует Android SDK и Android NDK.
- В архиве отсутствует Gradle Wrapper; без установленного Gradle/Android Studio его сначала нужно восстановить.
- Поэтому выполнить достоверную Android-сборку и приложить проверенный APK в этой сессии пока нельзя.

## Следующие действия

1. Импортировать содержимое архива в VatGram, сохранив текущие файлы проекта и исключив секреты.
2. Восстановить Gradle Wrapper и настроить Android SDK/NDK.
3. Сверить версии в README и Gradle.
4. Переименовать application label, package/applicationId и внутренние идентификаторы в ValGram.
5. Настроить Telegram API credentials локально, не публикуя их.
6. Собрать debug APK, исправить ошибки по фактическим логам, затем собрать release APK с отдельной подписью ValGram.
7. Проверить запуск и основные сценарии приложения на Android-устройстве/эмуляторе.
